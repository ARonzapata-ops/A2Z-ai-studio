Required server contract

The app sends a POST request using multipart/form-data with these fields: lyrics, style, voice_sample, optional reference_audio, and model_label. The server should return generated audio as the response body (audio/wav, audio/mpeg, or another playable audio type), or JSON containing an audio_url that the browser can access.

The server must allow requests from your app's website (CORS), protect any provider credentials server-side, and implement actual singing generation. GitHub Pages only hosts the interface; it does not run the AI model.

WAV export

Recorded samples and imported audio can be converted to a mono 16-bit PCM WAV file in the browser when the browser can decode the source format. Large audio files may take a little time on iPhone.
